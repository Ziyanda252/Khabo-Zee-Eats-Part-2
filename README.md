## Project Review

Khabo Zee's Eats is a food-based website designed to showcase the business's food products and services in a simple and user-friendly way. The website provides visitors with information about the business, its food offerings and other relevant details.

The project focuses on creating a clear online presence for Khabo Zee's Eats while applying important web development principles and techniques.

## Part 2 – CSS Styling and Responsive Design

For Part 2, the Khabo Zee's Eats website was updated with an external CSS stylesheet and responsive design.

### Changes Made
- Created and linked an external `css/style.css` stylesheet.
- Added consistent colours, fonts, spacing, headings and page styling.
- Used Flexbox for the gallery and responsive navigation.
- Added hover, focus and active effects.
- Implemented responsive design using CSS media queries.
- Added responsive logo images using `srcset` and `sizes`.
- Tested the website at desktop, tablet and mobile screen sizes.
- Updated the website pages and navigation.

## Part 3 – Website Functionality and Improvements

### Changes Made
- Added an interactive OpenStreetMap view showing Vilakazi Street, Soweto.
- Improved the contact and enquiry forms with HTML5 and JavaScript validation.
- Added email draft functionality to help users prepare their enquiries.
- Implemented menu search and filtering for food items.
- Added a dynamic featured dishes section.
- Added an FAQ section using interactive expandable content.
- Improved SEO through page titles, meta descriptions, `robots.txt` and `sitemap.xml`.
- Tested the contact and enquiry forms to confirm that validation and email drafts work correctly.
